# Custom Password Generator (Python)

A secure, flexible command-line application built in Python that generates strong, randomized passwords based on user-defined criteria. Designed to help users create robust passwords that meet modern security standards.

---

## 🛠 Features

- **Custom Length Specification:** Allows users to define the exact length of the generated password.
- **Character Set Control:** Options to include/exclude:
  - Uppercase letters (`A-Z`)
  - Lowercase letters (`a-z`)
  - Digits (`0-9`)
  - Special symbols (`!@#$%^&*()`, etc.)
- **Input Validation:** Ensures valid numerical inputs and prevents invalid selections.
- **Randomization:** Uses Python’s `random` module for unpredictable character selection.
- **Interactive Console Interface:** Clean and intuitive CLI prompts.
